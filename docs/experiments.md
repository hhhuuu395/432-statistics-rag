## 2026-10-05 — 阶段一：数据探查、技术选型、评测集清洗试验

### 1. 数据探查结论
- materials 构成：教材笔记 28、模拟卷 10、真题 1、答疑记录 6。
- 答疑记录几乎全是微信/企业微信聊天截图（图片），非文本：
  - 五月/七月/八月/九月答疑 zip = 截图（约 900 张），是「真实学生问题 + 标准答案」的主要载体。
  - 结构化文本只有两块：`中南大学智库.xlsx`（专业课考点问答，单单元格多行脏格式，6 格）、`常见问题集锦.docx`（备考规划类）。

### 2. 产品方向决策
- 核心 = 知识点答疑；规划类是附带功能。
- 截图提取（多模态 LLM）是**核心工作**，是评测集主要来源；不全量 OCR，跳过规划/闲聊，只处理知识点相关。

### 3. 技术选型
- 生成模型：DeepSeek（可用模型：`deepseek-flash` / `deepseek-v4-pro`）。
- 截图提取模型：DeepSeek `deepseek-flash`（视觉），兜底 Qwen-VL（若视觉端不稳定）。
- 脱敏约定：提取时当场改写——姓名/昵称→`[学生N]`、头像省略、其它个人标识→`[脱敏]`、老师发言不脱敏。
- key 存本地 `.env`（已 gitignore），不进仓库。

### 4. 实验 A：智库.xlsx 清洗
- 6 个单元格 → 7 条问答。
- 规则：`院校/问题/答案/问/答` 键值行解析；嵌套追问拆成独立问答；无键续行归入当前字段；`通知/补充` 噪声丢弃。
- 结果：7 条中知识点类仅 2–3 条，规划类为主 → 印证「结构化文本里知识点类太薄」。

### 5. 实验 B：截图提取小批量试验（八月前 15 张）
- 结果：15/15 判定「知识点」，14 张提取出问答对，0 解析失败；脱敏生效。
- 好样例：t 检验/F 检验等价性问题、指数 p/q 顺序问题、一张图多轮问答正确拆分。
- 发现 4 类数据质量问题，处理策略【已确认 2026-10-05】：
  1. 语音回复无法提取 → 答案缺失：标 `[语音-缺失]`，进「待补录清单」，不进答案比对。
  2. 题目/笔记在图片里 → 问题为模型转写，非学生原话（接受，作真实问题保留）。
  3. 「确认型」问答（答案=「对的/没问题」）→ 打「确认型」标签单列，**不进 RAG 检索评测主指标**。
  4. 空问答对 → 标「无文本问答对」，批量后人工抽看。
- 效率：`deepseek-flash` 每张 ~1900 tokens（含 ~500 推理 tokens）。成本估算全量仅几块钱，**不做推理优化，直接跑**。

### 6. 下一步（已确认的执行顺序）
- 生成「待补录清单」：语音回复的问题单独整理，老师用文字重写答案后并入正式评测数据（真实问题 + 标准答案，质量更高）。
- 批量前混测：从五月/七月/九月各抽 3–5 张混测，确认无系统性差异后再放量。
- 批量 OCR 四个月 ~900 张截图。
- 智库 7 条 + 截图提取 → 合并成统一评测集数据文件（标注来源：真实/构造；分类：知识点/规划）。
- 搭建 RAG 最小闭环（文档解析 → 检索 → 生成 → 评测）。

## 2026-10-06 — 阶段三：RAG 基线（Step 1）

### 基线结果（282 条硬问答，BGE-M3 dense 检索 top-8 + deepseek-flash 生成；语料=文本版源 1146 块，无茆书）
- 数学基础（n=153）：答案准确率 4.9%，平均相关性 1.21 —— 检索几乎无用，印证「统计教材帮不上纯数学」。
- 统计专业课（n=129）：答案准确率 16.7%，平均相关性 1.6。
- 按章节：假设检验 61%（n=9）、回归 23%、描述统计 21%、统计量 15%、多维 13%、参数估计 13%、随机变量 8%、随机事件与概率 0%、大数定律 0%（n=1）。

### 初步观察（badcase 信号，待 Step 2 定位）
1. 检索相关性普遍低（1.2–1.6/3）→ 主瓶颈是检索，dense 检索没找到相关块。
2. 数学基础 4.9% → 这层主要靠模型自身数学能力，检索无解。
3. 假设检验 61% 异常高 → 需查是覆盖好还是评测偏差。
4. 随机事件与概率/大数定律 0% → 疑似语料缺失。
5. 语料缺茆书（扫描版未 OCR）→ 大概率是检索差的根因之一，对应 Step 3。

### 产出
- data/report.json（基线报告）；索引 D:/86130/faiss_index（1146 块）。

### 下一步（Step 2）
- badcase 分析：抽统计专业课里答案错 / 相关性低的样本，定位「语料缺失（需茆书 OCR）」vs「检索/分块/生成」问题。

## 2026-10-06 — 阶段四：badcase 归因分析（Step 2）

### 归因分布（30 条统计专业课，分层抽样）
- 语料缺失 14（47%）、生成没用好 6（20%）、检索未召回 6（20%）、judge误判 1（3%）、非badcase 3（10%）。
- 失败样本（27 条）里：语料缺失 52%、生成没用好 22%、检索未召回 22%、judge误判 4%。

### 结论
1. 语料缺失是最大头（约一半）→ 茆书 OCR 是最高杠杆（Step 3）。
2. 生成没用好 + 检索未召回各约 22% → 检索质量（混合/重排）与 prompt 也是重要改进点。
3. 语料缺失集中章节：分布函数定义、样本方差 n/n-1、极坐标变换、摸球期望、概率赛制 → 对应茆书第 1–6 章。

### Step 3 OCR 建议（按优先级）
- 随机事件与概率（基线 0%，语料全缺）、随机变量及其分布、多维随机变量及其分布、统计量及其分布、参数估计 → 即茆书前 6 章。
- 假设检验（基线已 61%）可暂缓。

### 产出
- data/badcase_analysis.json（30 条完整明细）、src/eval/badcase.py（归因脚本）。

### OCR 范围与方法

### 复测结果（含茆书 vs 无茆书基线）
- 统计专业课：答案准确率 16.7% → **26.4%**（+9.7pp，相对 +58%），平均相关性 1.60 → 1.67。
- 数学基础：4.9% → 8.5%（仍低，符合「检索帮不上纯数学」）。
- 按章节：随机事件与概率 0→22%、随机变量 8→24%、统计量 15→27%、回归 23→33%、描述统计 21→32%、参数估计 13→21%；多维 13→13%（flat）、大数定律 0（n=1）。

### 结论
1. 茆书 OCR 是高杠杆（印证 badcase「语料缺失 52%」）→ 统计专业课准确率相对 +58%。
2. 检索相关性提升不大（1.60→1.67）但准确率明显提升 → 检索到了「对的内容」，粗 1-3 分相关性指标不敏感。
3. 剩余瓶颈：多维随机变量（数学重，flat）、数学基础（8.5%）、少量 OCR 垃圾页（URL 编码乱码）。

### 下一步（Step 4 候选）
- 混合检索（BM25）+ 重排（BGE-reranker），针对「检索未召回 22%」。
- 清理 OCR 垃圾页。
- 多维随机变量/数学基础是否专项处理，待定。

## 待办（升级优先级）
- 【高】留存验证：prompt 已对同一评测集迭代多轮（基线→茆书→混合检索→本轮），可能过拟合；最终需用老师新出的题（来源=构造）做 held-out 验证。
- 【高】老师针对薄弱章节自己出题补评测（来源=构造），既改善薄弱章节样本量，也充当留存验证集。
- 第 7 章（假设检验）要不要 OCR：等 Step 4 复测后，按剩余 badcase 再定。

## 方法学局限（记录）
- 评测集是同一批真实答疑记录（377 条截图 + 智库 7 条）；prompt/检索多轮迭代都在它上面调，指标提升有过拟合评测集的风险。最终结论需用老师新出的、未参与调参的题目做留存验证。

## 2026-10-07 — 阶段六：混合检索 + reranker 复测（Step 4）

### 复测结果（含茆书 + 混合检索 vs 含茆书 dense-only）
- 统计专业课：答案准确率 26.4% → 26.4%（**持平**），平均相关性 1.67 → 1.78（小升）。
- 数学基础：8.5% → 10.1%，相关性 1.18 → 1.32。
- 分章节涨跌互现（随机变量 24→30%、多维 13→20% 升；假设检验 61→56%、回归 33→23% 降），n 小（9–25）噪声大。

### 结论（诚实）
1. 混合检索（自实现 BM25 + BGE-reranker-v2-m3 + RRF）这一版**没有带来答案准确率的净提升**（持平 26.4%），仅相关性小升。
2. 瓶颈已从「语料缺失」（茆书 OCR 已解决）转移到「**生成没用好**」（badcase 占 22%）——检索到了对的内容，但生成/judge 没把它变成对的答案。
3. 按路线 C「用评测数据证明有效再留」：reranker 本轮不显著，可作回退项（dense-only 更简单）。

### 下一步方向（Step 4 转向）
- 重点转向「生成/prompt 质量」：优化 prompt、计算题切 deepseek-v4-pro、改进 judge。
- reranker 去留：可回退 dense-only 简化，或再调参（reranker 截断长度/候选数）试一轮再定。

## 2026-10-08 — 阶段七：第二轮 badcase（生成失败归因）

### 归因分布（35 样本，10 条「相关性≥2 但答案错」的生成失败）
- prompt没压住 8（80%）、该换更强模型 1（10%）、judge误判 1（10%）。

### prompt没压住的主要子问题
1. 误判「资料不足」：检索到了相关内容，模型却说资料不足（如「真实水平」术语）。
2. 答非所问：没理解简短问题指代（如「不是有正有负吗」）。
3. 答反/漏要点：如「不管方差知不知道都用 z 检验」标准答案「是的」，模型答「不是」。

### 结论：改 prompt，不换模型
- 只有 1/10 需要更强模型（正交变换证明题）。主因是 prompt 的「资料不足」指令被过度使用。
- 建议 prompt 改法：①「资料不足」改为「基于资料尽力回答，只有完全无关才说不足」；②加「直接简洁、先结论后解释」；③简短指代问题结合检索块推断上下文。

### 产出
- data/badcase_gen.json、src/eval/badcase_gen.py

## 2026-10-08 — 阶段八：prompt 优化复测 + 编造率 A/B（Step 4 收尾）

### 改动（唯一变量 = prompt；检索、裁判、模型均不变）
按阶段七结论改 prompt 三处：
1. 弱化兜底指令：「资料不足就说资料不足，不要编造」→「基于资料尽力回答…只有资料与问题完全无关时才说明资料不足」。
2. 新增「直接简洁，先给结论再简要解释」。
3. 新增「简短/含指代的问题（这个题、这一步）结合资料块推断所指」。
旧 prompt 保留为 `build_prompt_old` 供 A/B。

### 全量复测（n=282，同检索、同裁判、同模型）

| 层 | Step 4（旧 prompt） | 本轮（新 prompt） | Δ |
| --- | --- | --- | --- |
| 统计专业课 | 26.4% / 相关性 1.78 | **35.7% / 1.71** | +9.3pp / −0.07 |
| 数学基础 | 10.1% / 相关性 1.32 | **24.2% / 1.28** | +14.1pp / −0.04 |

按章节准确率：参数估计 20.8→37.5、统计量 23.5→41.2、描述统计 32.4→44.1、方差分析与回归 23.3→36.7、多维 19.6→26.1、假设检验 55.6→61.1、随机变量 30→34；随机事件与概率 16.7 持平（n=9）。涨分覆盖面很广，不是单章侥幸。

### 编造率 A/B（两层各 30 条，同题跑新旧 prompt 各一遍）

| 层 | 旧 prompt | 新 prompt | 净变化 | 翻转（无→有 / 有→无） |
| --- | --- | --- | --- | --- |
| 统计专业课 | 18/30 = 60% | 17/30 = 57% | −1 | 7 / 8（偏向减少） |
| 数学基础 | 17/30 = 57% | 17/30 = 57% | 0 | 5 / 5（完全对称） |

- 结论：**两层编造率都没有上升**。改动 1 在涨 +9.3pp/+14.1pp 的同时，编造未上升。
- 涨幅最大的数学基础层，双向翻转 5/5 完全对称，无任何单向迁移迹象。
- **「改动 1 是否矫枉过正」结案：否。** 判据 = 编造率净变化 + 翻转方向是否单向。
- 残留局限：二元「有编造」判级把「模型用自身知识答对」和「编造幻觉」混为一谈；本结案只证明「硬答没变多」，不等于「多答的都答对了」。

### 关键发现（方法学）

1. **【结论表述标准】LLM 裁判有不可复现的噪声地板 ≈ 相关性 0.05–0.12。**
   `judge_relevance` 两轮输入完全相同（检索是确定性的），平均相关性却从 1.78→1.71、1.32→1.28；分章节里多维 1.61→1.48、随机变量 1.84→1.72，另几章又完全不变（方差回归 2.27、统计量 1.35）。
   → **后续所有评测结论，小于 1pp 的分数差异一律不做精读、不当作结论**；报告改动效果时须同时给出样本量与噪声地板。

2. **【已确认】数学基础层的涨分来自模型自身知识，不是检索。**
   依据：① 该层检索相关性仅 1.28（≈「不足」），检索基本没帮着；② 该层编造率新旧持平（57%→57%，双向 5/5），说明新 prompt 下多答的部分并没有更多「编造」，而是把原本就有的自身知识更多地表了出来；③ 对照统计专业课（相关性 1.71）涨幅反而更小（+9.3pp vs +14.1pp）。
   → 下一步考虑**分层策略**：检索相关性低时，数学基础题允许模型用自身知识作答；统计专业课必须锚定资料（标注引用来源），资料不足时明确说明。

3. **旧 prompt 基线编造率就已达 57–60%**：说明「资料不够但硬答」在改 prompt 之前就是常态，根子在检索覆盖，不在 prompt 措辞。
